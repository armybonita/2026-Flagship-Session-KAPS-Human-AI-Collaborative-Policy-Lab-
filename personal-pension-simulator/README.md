# 개인 국민연금 시뮬레이터

국민연금 정책 대안이 개인의 예상 연금과 부담에 미치는 영향을 비교하는 공개형 웹 시뮬레이터입니다.

## 공개 데모

[개인 국민연금 시뮬레이터 열기](https://personal-pension-simulator-v2.army78.chatgpt.site)

## 주요 기능

- 현재 나이, 월소득, 예상 가입기간, 최종 은퇴연령 입력
- 정책 대안별 예상 월연금 비교
- 연금 수급 개시 시점과 은퇴 후 소득공백 계산
- 평균 기대수명 83.5세 기준 예상 생애 총수급액 계산
- 개인 조세, 국민연금 보험료, 국고부담 환산액을 반영한 연간 부담률 비교
- 개인혜택, 세대 간 형평성, 재정 안정성, 정책의 장점과 유의점 해설
- 입력값과 결과를 브라우저에서만 처리하는 개인정보 보호형 구조

## 유의사항

현재 계산값은 정책실험과 교육을 위한 단순 추정치입니다. 실제 국민연금 수급액, 보험료 및 세금은 가입 이력, 소득 재평가, 법령, 물가, 크레딧, 수급 시점 등에 따라 달라질 수 있습니다. 실제 재무·연금 의사결정에는 국민연금공단의 공식 조회 결과와 전문가 상담을 이용해 주세요.

## 기술 구성

- React / TypeScript
- Vinext
- Vite
- Cloudflare Workers 호환 빌드
- OpenAI Sites 배포 설정

## 로컬 실행

### 요구 환경

- Node.js 22.13 이상
- npm

### 설치 및 개발 서버

```bash
npm ci
npm run dev
```

### 빌드 및 검증

```bash
npm run build
npm test
```

## 주요 소스

- `app/page.tsx`: 입력, 계산모형, 정책 대안 비교 및 해설
- `app/globals.css`: 반응형 UI와 접근성 스타일
- `app/layout.tsx`: 페이지 메타데이터와 공통 레이아웃
- `tests/rendered-html.test.mjs`: 렌더링 결과 검증

## 개인정보 처리

이 버전은 사용자가 입력한 개인정보를 중앙 서버에 저장하지 않습니다. 계산은 브라우저에서 수행되며 결과는 해당 사용자 화면에만 표시됩니다.
